 CampusConnect – College Event Management System

CampusConnect is a web-based College Event Management System designed to make discovering, organizing, and managing college events easier for students and administrators.

The platform provides a centralized space where students can explore events, register individually or as a team, and access their registration details. Administrators can manage events, registrations, payments, and refund records.

-------- Features --------

###  Student Dashboard
- Explore upcoming college events.
- View event details and posters.
- Search and filter events.
- Register for individual or team events.
- View registered events.
- Generate QR-based registration passes.
- Receive cancellation notifications.

###  Admin Dashboard
- Admin login interface.
- View dashboard statistics.
- Add, edit, and delete events.
- Upload and manage event posters.
- View student registrations.
- Review and verify payment submissions.
- Manage refund records for cancelled events.

##  Technologies Used

- **HTML5** – Website structure.
- **CSS3** – Styling and responsive layout.
- **JavaScript** – Interactive features and application logic.
- **LocalStorage** – Browser-based data storage.
- **QRCode.js** – QR code generation.

##  How to Run the Project

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Explore the student and admin interfaces.

No additional installation is required for the basic frontend.

##  Project Notes

- The application uses browser LocalStorage for data persistence.
- Data is stored locally in the browser rather than in a centralized database.
- Payment verification and refund management are represented through the application's interface and records; actual money transfers are not performed.
- QR codes are generated as registration passes.

## Project Objective

The objective of CampusConnect is to simplify college event management by bringing event discovery, student registration, and administrative operations together in one platform.
